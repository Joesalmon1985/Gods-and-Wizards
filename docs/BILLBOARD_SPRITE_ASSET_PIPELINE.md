# Billboard Sprite Asset Pipeline (Run I — I10)

Doom-style billboards for 3D macro and tactical presentation.

---

## Folder structure (planned)

```text
godot_game/assets/billboards/
  heroes/
  demons/
  cities/
  wizards/
  ui_status/
  manifest.json
```

---

## Workflow

1. Select assets from [donor_asset_reuse_matrix.csv](donor_asset_reuse_matrix.csv) (generated by `scripts/audit_donor_assets.py`); Run J shortlist in [RUN_J_PLANNING_DARK_FANTASY_REUSE.md](RUN_J_PLANNING_DARK_FANTASY_REUSE.md).
2. Copy approved PNGs into class folders; record donor `source_path` in manifest `notes`.
3. Godot import: Filter OFF, Mipmaps ON.
4. Register in `manifest.json`:

```json
{
  "id": "hero_default",
  "path": "heroes/hero_default.png",
  "anchor": "feet",
  "scale": 1.0
}
```

5. Loader maps entity type + state → billboard texture in `BoardStateVisualizer` (Impl I6).
