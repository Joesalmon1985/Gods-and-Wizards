# Asset Prompt Library (Run I — I11)

**Style anchor:** Low-fantasy strategy board game, readable at 64px, slight painterly, neutral background, single subject centered.

Append to every prompt: `transparent background, game sprite, no text, no watermark`

---

## Heroes

```text
Billboard sprite, fantasy militia hero with spear and cloak,
three-quarter view, low poly painterly style, earth tones,
transparent background, game sprite, no text
```

Variants: `archer`, `cavalry`, `mage_support`

---

## Demons

```text
Billboard sprite, horned underworld imp, red and charcoal,
menacing but readable silhouette, strategy game unit,
transparent background, game sprite
```

---

## Cities

```text
Billboard sprite, medieval settlement with walls and banner,
small footprint, warm stone colors, strategy game building icon
```

Tiers: village → town → city (optional swap set)

---

## Wizards

```text
Billboard sprite, robed god-wizard with staff and glowing eyes,
vertical silhouette, purple and gold accents, strategy game hero
```

---

## Status icons (micro combat)

```text
Flat icon, {effect name} buff symbol, 64x64, bold outline,
dark fantasy UI icon, transparent background
```

Replace `{effect name}`: poison drip, barrier hex, silence rune, etc.

---

## Hex terrain tiles (optional)

```text
Top-down hex tile texture, {biome}, subtle grain,
seamless edges for hex grid, strategy game map tile
```

---

## Consistency checklist

- Same light direction (upper-left)
- Same vertical scale (hero ≈ 1.0, city ≈ 1.2)
- No photorealistic faces at small size
